# TGS-tg-bot
Telegram bot for recoloring animated TGS stickers and Premium emoji with pack creation, HEX colors, user history, SQLite statistics and admin panel.



# Sticker & Emoji Recolor Bot

Telegram-бот на **aiogram 3** для перекраски анимированных **TGS/Lottie-стикеров** и Telegram Premium emoji. Бот умеет перекрашивать один стикер или весь стикерпак, создавать новый пак через Telegram Bot API, хранить историю действий и давать администратору базовую панель управления.

## GitHub Description

Telegram bot for recoloring animated TGS stickers and Premium emoji with pack creation, HEX colors, user history, SQLite statistics and admin panel.

## Возможности

- Перекраска одного анимированного TGS-стикера или премиум-эмодзи.
- Перекраска целого стикерпака с прогрессом обработки.
- Создание нового стикерпака или custom emoji pack через Telegram Bot API.
- Палитра готовых цветов и ввод своего цвета в HEX-формате.
- Поддержка русских и английских названий цветов, например `красный`, `blue`, `gold`.
- Личный раздел пользователя с историей перекрасок и ссылками на созданные паки.
- HTML-интерфейс Telegram с inline-кнопками и premium emoji.
- SQLite-хранилище пользователей, истории, настроек, рассылок и админ-логов.
- Админ-панель с общей статистикой, поиском пользователей, баном, разбаном, топом пользователей, логами и рассылкой.

## Стек

- Python 3.8+
- aiogram 3.7.0+
- python-dotenv
- SQLite
- Telegram Bot API

## Структура проекта

```text
.
├── bot.py             # основной код бота, обработчики, FSM, SQLite и перекраска TGS
├── bot_database.db    # локальная база данных SQLite, создается автоматически
├── .env               # локальные переменные окружения, не публиковать в GitHub
└── readm.txt          # старые краткие заметки по запуску
```

## Быстрый старт

1. Создайте и активируйте виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Установите зависимости:

```bash
pip install "aiogram>=3.7.0" python-dotenv
```

3. Создайте файл `.env` в корне проекта:

```env
BOT_TOKEN=1234567890:your_bot_token_here
ADMIN_IDS=123456789,987654321
```

4. Запустите бота:

```bash
python bot.py
```

При первом запуске бот автоматически создаст таблицы в `bot_database.db`.

## Переменные окружения

| Переменная | Описание |
| --- | --- |
| `BOT_TOKEN` | Токен Telegram-бота из BotFather. |
| `ADMIN_IDS` | ID администраторов через запятую. Эти пользователи получают доступ к `/admin` и `/set`. |

## Как пользоваться

1. Откройте бота в Telegram и отправьте `/start`.
2. Нажмите кнопку перекраски или сразу отправьте анимированный TGS-стикер.
3. Выберите режим: один стикер или весь пак.
4. Выберите готовый цвет или отправьте свой HEX, например `#FF5733`.
5. Введите имя нового пака латиницей, цифрами или подчеркиваниями.
6. Получите ссылку на созданный стикерпак или emoji pack.

## Команды

| Команда | Описание |
| --- | --- |
| `/start` | Главное меню пользователя. |
| `/help` | Справка по использованию. |
| `/cancel` | Отмена текущего действия. |
| `/admin` | Админ-панель, доступна только ID из `ADMIN_IDS`. |
| `/set <key> <value>` | Изменение настройки в SQLite, доступно только администраторам. |

## Админ-панель

Администратор может открыть панель командой `/admin`. В ней доступны:

- статистика пользователей и перекрасок;
- список и топ пользователей;
- поиск пользователя по ID, username или имени;
- просмотр информации о пользователе и последних действиях;
- бан и разбан пользователей;
- рассылка HTML-сообщения всем незаблокированным пользователям;
- просмотр логов админских действий;
- просмотр и изменение простых настроек через `/set`.

## База данных

Бот использует SQLite и создает таблицы автоматически:

- `users` - пользователи, премиум-статус, бан, активность и счетчики;
- `recolor_history` - история перекрасок, цвет, тип действия и количество элементов;
- `admin_log` - действия администраторов;
- `settings` - простые key-value настройки;
- `broadcast_history` - история рассылок.

Для чистого запуска можно удалить `bot_database.db`: при следующем запуске бот создаст новую пустую базу.

## Ограничения

- Поддерживается только формат **TGS**. Статичные и WEBM-стикеры не перекрашиваются.
- Перекраска работает через изменение цветовых свойств Lottie JSON и может не идеально обработать сложные анимации с нестандартной структурой.
- При обработке всего пака бот пропускает неподдерживаемые элементы.
- В коде установлен лимит до 120 стикеров в одном паке.
- Для создания sticker set или custom emoji pack используются ограничения Telegram Bot API.

## Проверка перед запуском

Быстрая проверка синтаксиса:

```bash
python3 -m py_compile bot.py
```

Проверка запуска без токена завершится сообщением в логах о том, что `BOT_TOKEN` не задан. Для полноценной проверки нужен реальный токен Telegram-бота.
